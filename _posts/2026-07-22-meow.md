## Scenario

The first machine in HackTheBox's Starting Point track — a deliberately simple introduction to the core loop of every engagement: connect, scan, identify, exploit, capture.

## Machine overview

| Field | Value |
|---|---|
| Platform | HackTheBox Starting Point |
| Difficulty | Very Easy |
| OS | Linux |
| Objective | Gain root-level access and capture the flag in root's home directory |

## Phase 1: Connectivity check

```bash
ping <target-ip>
```

Confirms the target is reachable over the HTB VPN connection before doing anything else.

## Phase 2: Port scanning

```bash
nmap -p23 <target-ip>
```

```
PORT   STATE  SERVICE
23/tcp open   telnet
```

**Finding:** Telnet — an unencrypted, largely obsolete remote-access protocol — was open and accessible.

## Phase 3: Exploitation

```bash
telnet <target-ip>
```

Login prompt accepted the username `root` with a **completely blank password** — no credential brute-forcing or exploit development required. This is a textbook example of the most basic possible misconfiguration: a privileged account left with no authentication at all.

## Phase 4: Flag capture

```bash
ls /root
cat /root/flag.txt
```

Dropped straight into a root shell via Telnet, the flag was sitting in root's home directory in plain text.

## Key takeaway

The lesson here isn't technical complexity — it's a reminder of how often real-world compromises come down to exactly this: a legacy service left running, with no password on a privileged account. No exploit chain needed when the front door was never locked.
